# 手机找车、多语言、货币换算与 WhatsApp

## 手机体验

- 页头分成品牌/主题/语言、联系按钮、导航三行。控制最小点击区域，长语言名称允许换行。
- 手机找车球缩为 64px，固定在右下方，不再跟随顶部 WhatsApp 挤压正文。
- 点击打开独立弹层；背景压暗、虚化、禁止滚动并设置 inert。取消划过/手指经过就误开的交互。
- 首次打开三个入口折叠；品牌、车型、类型和预算按钮至少 48px。面板只有一个内容滚动区，关闭与直接联系保留独立位置。
- 键盘弹出时根据 visualViewport 调整可用高度；支持 Escape、Tab 焦点约束、点击遮罩关闭。关闭后保留选择。

## 语言

11 种完整语言：简体中文、英语、阿拉伯语、日语、荷兰语、法语、德语、意大利语、葡萄牙语、俄语、西班牙语。原先菜单的“即将推出”已移除，日语为新增选项。

首次按浏览器提供的系统语言偏好列表匹配，包括 ar-AE、ar-SA、en-AE、en-SA 等区域标签；手动选择优先并保留，“自动”恢复系统偏好。未支持的语言回退英语，不能声称支持世界上的每一种语言。浏览器不开放读取任意操作系统设置，也不能据此确定访客真实所在地。

正文、流程、FAQ、车辆详情、图片替代文字、动态提示和 WhatsApp 留言一并本地化。阿拉伯语设置 lang/dir，电话号码、金额、地图及地址保留适合的方向。当地文案采用适合商业网站的自然标准语；尚未经各语言母语审校。

翻译源：`tools/locales.tsv`。运行 `python tools/build-locales.py` 生成 `dist/site-i18n-data.js`。找车专用文案在 `dist/finder-i18n.js`。

## 日元录入、当地货币与美元显示

在 `dist/config.js` 的车辆对象设置 `priceJPY: 3000000` 等数值即可。前台从这一日元基准计算当地货币和美元，不额外显示第三个日元金额。当当地货币本身为美元时只显示一次。

真实的两辆车仍保持 `priceJPY: null`，未新增示例售价或编造车辆报价。填入日元价格后自动启用换算；无价车辆显示确认后报价。

- 接口：<https://open.er-api.com/v6/latest/JPY>，无需 API key，实测返回 166 种货币，包含 AED/SAR/USD。
- 数据源每日更新，金额在浏览器即时计算。页面显示汇率更新时间；这不是逐秒外汇行情，也不是结算承诺。来源按要求链接 ExchangeRate-API。
- 本地缓存验证来源币种、正数汇率及时间；过旧缓存不使用。接口失败明确说明缓存或不可用状态，不使用旧代码里的固定估算汇率。
- 根据区域偏好初选币种，可手动修改。阿联酋 AED、沙特 SAR；国家与语言分开设置。未能可靠确定的国家需要访客确认，不能通过“说阿拉伯语”判定所在国。
- 网页运行和换算均不调用 AI、不消耗 AI token；没有新增付费服务。开发对话本身仍有正常 token 使用。

## WhatsApp

主按钮、页头、页尾、车辆详情及找车品牌/类型/预算入口使用同一语言和目的国家。提供 249 个国家及地区选项；首次可从明确的区域标签初选，访客可修改。

留言保留实际品牌/车系/车型或预算，附本地化国家名称和首选显示货币。阿联酋与沙特分别填写各自国家；沙特阿拉伯语问候使用“السلام عليكم”。未选择国家则不写入假定目的地。切换国家、语言或货币同步更新找车链接。

## 验证与发布

- 220 项 DOM/逻辑断言：11 语言与回退、手动/自动偏好、阿联酋/沙特语言与币种、20 品牌/460 车系、7 类型、预算、弹层开关与选择保留、键盘可用高度、日元换算、缺价、缓存/离线、国家留言、禁用 localStorage。
- 自有 JavaScript 语法、HTML 本地资源路径和 ID 唯一性检查通过。
- 当前没有可连接的浏览器；未完成手机实机、真实浏览器排版/遮挡和动画视觉验收。DOM 模拟不同尺寸不能替代此项验收。
- 沿用现有 GitHub → Cloudflare Pages 发布路径和 `megumi-site/dist` 输出目录，不另建站点、不改变访问权限。

测试命令：`node tools/verify-locales-prices.mjs <happy-dom/lib/index.js的绝对路径>`。

参考：<https://www.exchangerate-api.com/docs/free>、<https://developer.mozilla.org/en-US/docs/Web/API/Navigator/languages>、<https://developer.mozilla.org/en-US/docs/Web/HTML/Global_attributes/dir>。
