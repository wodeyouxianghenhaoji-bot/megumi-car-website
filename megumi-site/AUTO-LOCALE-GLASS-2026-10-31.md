# 自动语言、自动货币与玻璃细节修正

- 修复旧的手动语言选择覆盖系统偏好的问题：每次访问或刷新都默认自动，忽略历史手动选择。明确手动选择仅用于当前页面，之后重新打开仍跟随系统；系统/浏览器语言变化时立即恢复自动匹配。
- 网站只能读取浏览器开放的语言偏好，不能直接读取浏览器未开放的操作系统设置。仍为 11 个已翻译语言，其他语言回退英语。
- 默认显示货币优先匹配当前页面语言对应的浏览器区域标签，例如 en-US → USD、en-GB → GBP、en-AU → AUD、ar-AE → AED、ar-SA → SAR。没有同语言区域线索时采用该页面语言的默认显示货币；例如在日文系统里手动切换为英语且没有英语区域线索时，改为 USD，不继续保留 JPY。
- 旧版缓存的手动币种不再影响默认自动匹配。需要更正时仍可手动选择，但切换页面语言或系统语言后会重新自动匹配。运输目的地与界面显示币种独立，不依据币种修改顾客的运输目的地。
- 移除显眼的国家大按钮，改成无需操作的小字当前币种入口。国家大字、符号小字的选项仍保留在可选更正面板内。
- 找车面板去掉原蓝灰色实心底，换为低填充透明玻璃，内容、底部和遮罩同步降低填充；浅色主题适配文字对比。
- 联系按钮外缘改为单层 0.33 CSS px 内侧细线，实线边框为 0；取消叠加轮廓及内侧粗高光。其他 Logo、内容及联系信息不变。

## 检查

504 项 DOM/逻辑检查通过，包含 11 种语言在历史设置存在时仍自动匹配、英语切换不再残留 JPY、系统语言变化自动切换、各国家区域货币匹配等场景。深浅主题下的样式计算结果确认：外框实线为 0，只有 0.33px 细线；面板内容和底部均为透明。此为 DOM/CSS 检查，不是实机截图验收。

访问排查：主站 `https://megumi-cars.pages.dev/` 及其 27 项直接引用资源，在使用浏览器或具名应用请求时均返回 HTTP 200，前次 Cloudflare 部署成功。默认 Python 客户端会被 Pages 平台返回 1010，此为平台针对非浏览器请求的检查，不足以判定用户浏览器报错原因。未修改 Cloudflare 安全设置。

用户报告的“打不开”尚未获得具体网址与错误信息，本环境没有真实浏览器连接，不能声称复现或排除了用户所在设备/网络的问题。
